git log Выводит список (ленту) коммитов в хронологическом порядке. Показывает хэш, автора, дату и сообщение коммита.
git show Показывает детали конкретного коммита: его метаданные и полный diff (какие именно строчки кода изменились).
git diff Напрямую сравнивает два состояния кода (индекс, рабочую директорию, коммиты или ветки) строчка за строчкой.
git log -S Эта команда ищет коммиты, в которых количество упоминаний заданной строки изменилось (строка была добавлена или полностью удалена).
git blame Эта команда построчно разбивает указанный файл и выводит метаданные для каждой строки
