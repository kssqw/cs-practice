Рабочая папка - это папка на компьютере, где можно видеть и редактировать файлы.
Индекс - временное хранилище, куда собираются изменения перед тем, как стать коммитом.
Коммит - снимок состояния проекта в истории Git, имеющий свой уникальный код.
Git -  локальная система контроля версий, которая работает на компьютере
GitHub -это облачный веб-сервис, где хранятся удаленные репозитории, чтобы кодом можно было делиться.
